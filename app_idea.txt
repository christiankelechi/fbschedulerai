1. Executive Summary & Objective
The objective of this project is to design, deploy, and maintain an autonomous content creation and
scheduling backend engine. The platform will periodically prompt zero-cost AI endpoints to generate
niche-relevant reflections, scriptural thoughts, and educational content, synthesize necessary
visual/video media artifacts, store these items in an optimized backend repository, and
programmatically publish posts and vertical video reels directly to Rev. Fr. Ejiogu Chukwuemeka’s
designated Facebook Page via the Meta Graph API without requiring daily manual intervention. 2. Infrastructure & Zero-Cost Architecture Strategy

3. System Scope & Functional Requirements
3.1 Content Generation Pipeline
- Autonomous Ideation: Celery Beat periodically triggers according to scheduled cron expressions
(e.g., daily reflections, morning prayers, or evening scriptures) pulling from curated prompt banks. - Zero-Cost LLM Ingestion: Dispatches requests to OpenRouter utilizing designated zero-cost
endpoints. The prompt schema enforces strict structured outputs (caption, scripture citations, hashtags, and visual prompt description). - Visual & Media Rendering: Generates branded quote cards and static graphics via Pillow/Hugging
Face. For video reels, the engine synthesizes audio using edge-tts, aligns vertical footage loops (9:16
aspect ratio), embeds styled captions via FFmpeg, and outputs compressed MP4 files ready for
distribution. 3.2 Facebook Publishing & Scheduling Engine
- Token Security & Storage: Encrypted storage of Facebook Page Access Tokens and Meta App
Secrets in protected environment variables. - Direct Feed & Media Publishing: Automated REST endpoints handling /{page-id}/feed and /{page￾id}/photos with dynamic image attachments. - Video Reels Upload Protocol: Implementation of Meta's 3-step Reels upload workflow: (1) Start
phase to generate reel video session ID; (2) Binary transfer directly to Meta rupload infrastructure;
(3) Finish phase to apply captions, visibility flags, and trigger indexing. - Error Handling & Automatic Retries: Posts that encounter network timeouts or transient Meta
rate-limit blocks are flagged as FAILED in Django Admin, and Celery retries the job with exponential
backoff up to 3 times before sending administrative alerts. 4. Technical Specifications & Stack
- Language & Framework: Python 3.12, Django 5.x, Django REST Framework.
- Asynchronous Queuing & Scheduling: Celery with Redis broker and Celery Beat scheduler. - Database Management: PostgreSQL (relational database for posts, schedules, logs, and token
vaults). - Server Environment: Ubuntu 24.04 LTS (Contabo VPS), Docker Compose, Nginx, Let's Encrypt SSL. - Video/Audio Toolchain: FFmpeg system binary, Python moviepy, and edge-tts. 5. Non-Functional Requirements & Free-Tier Constraints
Rev. Fr. Ejiogu Chukwuemeka explicitly acknowledges and agrees to the following operational
parameters inherent to a zero-cost API architecture: - Rate Limiting & Latency: Free AI endpoints (such as OpenRouter free tiers) may occasionally
experience queue delays or brief throttling during global peak hours. The software incorporates
retry handlers, but publishing down to the exact second cannot be guaranteed on free third-party
tiers. - Server Resource Management: Video rendering using CPU-based FFmpeg on the Contabo VPS will
be throttled and scheduled during off-peak hours to avoid saturating VPS RAM and CPU. - Meta Platform Policies: Automated posting operates strictly within Meta's published Graph API
terms of service. Developer is not responsible for policy updates or automated moderation actions
initiated by Meta. 6. Project Deliverables & Milestones
- Milestone 1: Server provisioning on Contabo, Nginx/SSL configuration, Meta Developer App
creation, and API token validation. - Milestone 2: AI pipeline integration (OpenRouter free model ingestion, graphic styling, edge-tts
audio synthesis). - Milestone 3: Celery task queue, automated scheduling engine, and Django administrative
monitoring dashboard. - Milestone 4: End-to-end testing, live scheduled deployment of image and video reel posts to the
Facebook Page, and handover.
