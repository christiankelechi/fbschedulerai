Autonomous Operational Flow

From 3:00 AM Cron to Facebook Page

A fully decoupled, four-stage automated pipeline ensuring zero downtime, zero cost, and 100% human editorial oversight.

01
Serverless Cron Trigger
Vercel automated cron schedules trigger serverless endpoints at 3:00 AM WAT (Morning Prayer) and 5:00 PM WAT (Evening Bible Study) without requiring a continuously running daemon.
CRON • 0 2 * * * / 0 16 * * *
02
Zero-Cost AI Curation
OpenRouter free tier (Meta Llama 3.2 3B) generates faithful Catholic reflections, scripture citations, and prayer points, while Pillow/HuggingFace crafts typography quote graphics stored on Cloudinary.
AI • OpenRouter + Pillow + Cloudinary
03
Zenia Review Forwarding
The full devotional, formatted caption, hashtags, and direct Cloudinary image download link are dispatched via the Zenia Email API directly to Christian Eze at {{ review_email }}.
NOTIFY • Zenia Email Dispatch
04
Facebook Publishing & Audit
Christian reviews the content from 6:00 AM, copies the text with 1 click or confirms posting. The custom admin dashboard audits daily compliance and updates the 7-day streak board.
AUDIT • Meta Graph API + Compliance

Core System Architecture

Enterprise Capabilities at Zero Cost

Designed with modern cloud and AI practices to eliminate monthly software overhead while maximizing reliability.

✝️
Orthodox Catholic Prompting
Fine-tuned system instructions honoring the Catechism, Roman Missal daily lectionary, liturgical seasons (Advent, Lent, Easter, Ordinary Time), and saints' feast days.
☁️
Cloudinary Media CDN
Automated typography quote cards and reel graphics are hosted on Cloudinary CDN, enabling instant high-res downloads and direct Meta Graph API uploads via URL.
📧
Zenia Email Forwarding
Decouples direct automated posting from human verification. Christian Eze receives the full body and image links hours ahead to verify accuracy and theology.
📊
Posting Compliance Center
High-fidelity dashboard tracks daily compliance status: "BOTH POSTED", "PARTIAL", or "MISSED", complete with a 7-day activity streak calendar.
🚀
Vercel Serverless Hosting
Runs entirely on Python Serverless Lambda functions with pre-collected WhiteNoise static files, eliminating expensive virtual machine hosting costs.
🛡️
Aiven Managed PostgreSQL
Resilient cloud database with automated IP resolution safeguards, preventing DNS timeout failures and guaranteeing ACID data persistence.
